SEMANA 12 / LISTAS + DICCIONARIOS + BUCLES

Todo comienza con los datos.

Una imagen guarda información en números. Primero, recorre una lista de intensidades y clasifica cada valor como claro u oscuro. Un diccionario te ayuda a organizar sus metadatos.

In [ ]Python 3
# Intensidades entre 0 y 255
brillos = [20, 100, 160, 250]
foto = {"nombre": "Asta", "ancho": 900, "alto": 560}

for pixel in brillos:
    estado = "CLARO" if pixel >= 128 else "OSCURO"
    print(pixel, estado)
print(foto["nombre"], foto["ancho"], "×", foto["alto"])
Ejecuta la celda para ver su salida.
¿Por qué 0 a 255?

Un canal de 8 bits tiene 256 valores posibles. El 0 representa ausencia de intensidad y el 255, la intensidad máxima. En gris se usa un solo canal; una imagen RGB tiene tres.

Qué hace esta celda

Convierte los tres canales de color en una sola intensidad de gris.

¿Qué diferencia hay entre gris, desenfoque, bordes y umbral?

Gris elimina la información de color. Gaussiano suaviza variaciones locales. Canny localiza cambios de intensidad y destaca contornos. El umbral binario crea solo dos valores: 0 y 255. En OpenCV, threshold asigna blanco cuando el valor es estrictamente mayor al umbral.
